# RupeePilot — The Money Multiverse

A long-form, India-first market and personal-finance experience.

## Features
- TradingView-powered interactive chart, market overview, stock screener, crypto market, heatmap and market news widgets.
- India, global-market and crypto chart presets.
- Browser-local manual portfolio snapshot (no brokerage connection or live valuation).
- SIP, EMI, FD and budget calculators with adjustable inputs.
- Responsive editorial layout, keyboard focus states, reduced-motion support and mobile navigation.

## Run locally
Open `index.html` in a modern browser. Market widgets require an internet connection and may show delayed or unavailable exchange data.

## Publish with GitHub Pages
Upload the contents of this folder to the repository root (not into a nested folder), replacing `index.html`, `styles.css`, `app.js` and `assets/favicon.svg`. Keep the existing policy pages and `.github/workflows/pages.yml`. GitHub Pages will deploy after the workflow completes.

## Data and important limitations
- Market visualisations are third-party TradingView widgets. Availability and delays depend on the exchange and provider.
- Portfolio entries are manual and stored in the visitor's browser only. They are not synced and do not fetch current prices.
- Calculators provide estimates for learning and planning, not guaranteed outcomes.
- RupeePilot is not a broker, exchange, financial adviser or investment recommendation service.
